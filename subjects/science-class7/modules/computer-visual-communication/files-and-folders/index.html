Files vs. folders

File

The output from any application — a picture, a document, a spreadsheet. Like an individual book on a shelf.

Folder

A storage space holding multiple files — like the whole bookshelf.

Notepad

Used to type and save notes as text files.

Paint

Used to draw and edit pictures.
