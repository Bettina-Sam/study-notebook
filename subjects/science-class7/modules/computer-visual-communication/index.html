Unit 7

Computer – Visual Communication

A computer isn't just for typing — it's a tool for organizing ideas and communicating them visually. This short unit covers how files and folders keep your work organized, and how tools like Paint and Photostory turn pictures into stories.

Learn in this order

Start with the basics of files and folders — how your work gets organized. Then try out visual communication tools yourself, including a mini drawing canvas and a step-by-step photo story builder.

Verified against the 2025 Term-1 textbook

Learning Objectives

  • Differentiate a file from a folder.
  • Know how to create a file and a folder.
  • Use the system application "Paint" to create images.
  • Use the system application "Photostory" to create video from images.
