Atomic number (Z) is the number of protons (= electrons) in an atom. Mass number (A) is the number of protons plus neutrons. Together, p + n = A.

Isotopes and isobars

Atomic number (Z)

Number of protons (= electrons) in an atom.

Mass number (A)

Number of protons + neutrons.

Isotopes

Same atomic number, different mass number — e.g. hydrogen's Protium, Deuterium, Tritium.

Isobars

Same mass number, different atomic number — e.g. Calcium-40 and Argon-40.
