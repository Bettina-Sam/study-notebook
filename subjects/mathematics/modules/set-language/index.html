Chapter 1

Set Language

You already sort things into groups without thinking about it. Set language just gives that habit a precise notation — one that turns out to describe collections, logic and even word problems about people and their hobbies.

Understand→Explore→Practise→Reflect

Learn in this order

Start with what a set even is and how to write one down, then the different kinds of sets you'll meet. From there, combine sets with the standard operations and picture them with Venn diagrams, discover the algebraic laws those operations follow, meet De Morgan's laws, and finish by using all of it to solve real counting problems.
