1.3 Representation of a Set

Three ways to write
the same set

Descriptive, set-builder and roster form are just three different languages for one idea — pick whichever reads clearest for the job at hand.

Activity 2

Choose a set below — see it in all three forms

Descriptive form describes the set in words. Set-builder form (or rule form) uses a variable and a condition — $\{x : x \text{ is ...}\}$, where "$:$" or "$|$" means "such that". Roster form simply lists every element. Tap each tab and check that all three descriptions below really do name the same set.

Worked Example

Example 1.2(ii) (textbook)
Write the set of letters of the word "PRINCIPAL" in Roster form.
1
Spell out every letter in order.
P, R, I, N, C, I, P, A, L
2
Keep only the distinct letters.
P, R, I, N, C, A, L
3
Final answer
$Y = \{P, R, I, N, C, A, L\}$

Try Yourself

Exercise 1.1 · Q2(i)
List the set of letters of the word "INDIA" in Roster form.
INDIA has 5 letters, but one repeats — how many distinct letters remain?
Answer: $\{I, N, D, A\}$ — the letter I appears twice but is listed once.
Exercise 1.1 · Q4(i)
Represent in Roster form: $A$ = the set of all even natural numbers less than 20.
"Less than 20" excludes 20 itself — the last term you include is 18.
1
List even numbers from 2, stopping before 20.
2
2, 4, 6, 8, 10, 12, 14, 16, 18
Answer: $A = \{2, 4, 6, 8, 10, 12, 14, 16, 18\}$
Exercise 1.1 · Q5(iv)
Represent in Set-Builder form: $E$ = the set of odd Whole numbers less than 9.
You need a variable, the type of number it is, and the bound — combine them with "such that" ($:$).
Answer: $E = \{x : x \text{ is an odd whole number}, x < 9\}$   — in roster form this is $\{1,3,5,7\}$.
