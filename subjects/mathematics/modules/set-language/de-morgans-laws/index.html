Augustus De Morgan — born in Madurai, Tamil Nadu — worked out exactly how "not" distributes over "and" and "or" for sets. These two laws are used constantly in later mathematics and logic.

1.7.2 De Morgan's Laws for Complementation

$(A \cup B)' = A' \cap B'$

"Not (A or B)" means the same thing as "not A, and not B". Compare the two shaded regions below — $U=\{a,b,c,d,e,g,i,o,u\}$, $A=\{a,e,i,o,u\}$, $B=\{b,c,e,o\}$.

Tap (A∪B)′ first, then compare with (A∩B)′.
(A ∪ B)′ = A′ ∩ B′
(A ∩ B)′ = A′ ∪ B′

1.7.1 De Morgan's Laws for Set Difference

$A - (B \cup C) = (A-B) \cap (A-C)$

Example 1.24 (textbook)
$P=\{1,...,9\}$, $Q=\{1,3,5,7,9\}$, $R=\{2,3,5,7,11,13\}$. Verify $P-(Q \cup R) = (P-Q) \cap (P-R)$.
1
$Q \cup R = \{1,2,3,5,7,9,11,13\}$, so $P - (Q \cup R)$
= {4, 6, 8}
2
$P - Q = \{2,4,6,8\}$ and $P - R = \{1,4,6,8,9\}$
3
$(P-Q) \cap (P-R)$
= {4, 6, 8}
4
Both sides equal {4, 6, 8} — verified.

Exercise 1.5 · Q10
$U=\{4,7,8,10,11,12,15,16\}$, $A=\{7,8,11,12\}$, $B=\{4,8,12,15\}$. Verify De Morgan's Laws for complementation.
Compute A∪B, then its complement. Separately compute A′ and B′, then intersect them. Compare.
$A \cup B = \{4,7,8,11,12,15\}$, so $(A \cup B)' = \{10,16\}$.
$A' = \{4,10,15,16\}$, $B' = \{7,10,11,16\}$, so $A' \cap B' = \{10,16\}$. ✓ Equal — law verified.

$A \cap B = \{8,12\}$, so $(A \cap B)' = \{4,7,10,11,15,16\}$.
$A' \cup B' = \{4,7,10,11,15,16\}$. ✓ Equal — law verified.
