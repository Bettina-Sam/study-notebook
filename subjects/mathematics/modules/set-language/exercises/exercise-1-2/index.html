Q7If $A=\{a,\{a,b\}\}$, write all the subsets of $A$.
Treat $\{a,b\}$ itself as a single element of A alongside $a$. Click every candidate below that IS a valid subset of A, then Check.
A has exactly 2 elements: the element "a", and the element "{a,b}" (a set-within-a-set). So it behaves like any other 2-element set for counting subsets — watch out for {b} and {a,b}, which are traps since b alone and the pair {a,b} written as a plain 2-element set are NOT elements of A.
Subsets: $\varnothing$, $\{a\}$, $\{\{a,b\}\}$, $\{a,\{a,b\}\}$ — 4 subsets in total.
