Q2Test the commutative property of union and intersection for:
$P=\{x : x \text{ is a real number between 2 and 7}\}$, $Q=\{x : x \text{ is a rational number between 2 and 7}\}$
$P$ and $Q$ have infinitely many elements, so the diagrams below use a small finite stand-in ($Q\subseteq P$, same as the real question) — press Compare and watch both circles shade at once.
Does the picture confirm $P\cup Q = Q\cup P$ and $P\cap Q = Q\cap P$?
Every rational number is also a real number, so $Q \subseteq P$. What does that make $P \cup Q$ and $P \cap Q$?
Since $Q \subseteq P$: $P\cup Q = P = Q\cup P$, and $P\cap Q = Q = Q\cap P$. Both orders give the same set — commutative property holds (as it always does for union and intersection, for any two sets).

$B$ has infinitely many elements ($8,10,12,\dots$) — the diagram below uses a finite sample $\{8,10,12,14,16\}$, which is enough since every element of $B$ is $\ge 8$, too big to matter here.
A ∩ (B ∩ C)

$B\cap C = \varnothing$ (every element of B is $\ge 8$, too big to be in C), so $A\cap(B\cap C)=\varnothing$.

Both sides equal $\varnothing$ — verified.
