Set Language
1.4 Types of Sets

Not every set
looks the same

Some sets have nothing in them, some have exactly one thing, some go on forever. Sorting sets into these categories is the vocabulary the rest of the chapter depends on.

01. Empty, Singleton, Finite, Infinite

Four basic shapes a set can take

∅Empty (Null / Void) Set — has no elements at all. Written $\varnothing$ or $\{\ \}$. E.g. the set of odd integers divisible by 2.
{a}Singleton Set — has exactly one element. E.g. the set of all even prime numbers = {2}.
nFinite Set — the counting stops somewhere. E.g. the set of all factors of 36.
∞Infinite Set — the counting never stops. E.g. {5, 10, 15, ...}, the set of all points on a line.

Note: the empty set is finite (it has zero elements, and zero is a number you can count to).

03. Equal Sets vs. Equivalent Sets

Same elements, or just the same count?

Two sets are equal ($A = B$) if they contain exactly the same elements. Two finite sets are equivalent ($A \leftrightarrow B$) if they simply have the same number of elements — equal sets are always equivalent, but equivalent sets need not be equal.

04. The Universal Set

The set of everything under discussion

A Universal Set $U$ contains every element relevant to the sets you're discussing. If $A = \{\text{Earth, Mars, Jupiter}\}$, a natural universal set is $U = $ all planets of the solar system — every set you'd compare $A$ against lives inside $U$.

Exercise 1.2 · Q2(iii)
Is $A = \{x : x \in Z, x < 5\}$ finite or infinite?
Z is the set of integers — it extends forever in the negative direction too.
Answer: Infinite — it includes 4, 3, 2, 1, 0, −1, −2, ... with no smallest integer.
Exercise 1.2 · Q4(iii)
Is $C = \{0\}$ a null set or a singleton set?
$\{0\}$ is not the same thing as $\{\ \}$ — it contains the number zero as an element.
Answer: Singleton set — it has exactly one element, the number 0.
