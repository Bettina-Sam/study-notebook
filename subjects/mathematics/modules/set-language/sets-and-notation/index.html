Set Language
1.1–1.2 What Is a Set?

A set is just a
well-defined collection

"Well-defined" is the whole trick: given any object, you must be able to say for certain whether it belongs to the collection or not — no arguing about it. The objects inside are called its elements or members.

02. Belongs To — ∈ and ∉

Test membership in $A$

If $x$ is an element of a set $A$, we write $x \in A$ (read "$x$ belongs to $A$"). If it isn't, we write $x \notin A$. Let $A = \{2, 3, 5, 7\}$ — the prime numbers less than 10.

Worked Example

Example 1.1 (textbook)
Consider $A = \{\text{Ashwin, Murali Vijay, Vijay Shankar, Badrinath}\}$. Fill in the blank with $\in$ or $\notin$ for: Ganguly ___ A.
Concept used: Ganguly is not one of the four named elements, so he does not belong to this set.
1
List the elements of A.
Ashwin, Murali Vijay, Vijay Shankar, Badrinath
2
Check whether "Ganguly" appears in that list.
It does not.
3
Final answer
Ganguly $\notin$ A

1
A = {0, 3, 5, 8}. Does 5 appear in this list? Yes.
2
Does 6 appear in this list? No.
Answer: $5 \in A$ is True.   $6 \in A$ is False (so $6 \notin A$).
