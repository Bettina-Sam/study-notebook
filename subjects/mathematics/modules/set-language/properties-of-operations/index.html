1.6 Properties of Set Operations

Do set operations
obey the same rules as numbers?

Numbers have commutative, associative and distributive laws. It turns out union and intersection follow the very same patterns.

1.6.1 Commutative Property

Order doesn't matter

For any two sets, $A \cup B = B \cup A$ and $A \cap B = B \cap A$. Let $A=\{b,e,f,g\}$, $B=\{c,e,g,h\}$ — switch the order below and watch the shaded region (and the result) stay identical.

1.6.2 Associative Property

Grouping doesn't matter

For any three sets, $A \cup (B \cup C) = (A \cup B) \cup C$ and $A \cap (B \cap C) = (A \cap B) \cap C$ — whichever pair you combine first, the final result is the same. Let $A=\{-1,0,1,2\}$, $B=\{-3,0,2,3\}$, $C=\{0,1,3,4\}$. Pick a law, then step through each grouping on its own diagram and watch both sides land on the identical shaded region.

1.6.3 Distributive Property

Union and intersection distribute over each other

Just like $a(b+c) = ab + ac$ for numbers:

A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)  — intersection over union
A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)  — union over intersection
