1.4 Subsets & Power Sets

Sets living
inside other sets

Once you can compare two sets, a whole new question opens up: is one of them completely contained in the other? And if so, how many ways can that happen?

1.4.8 Subsets — $\subseteq$

Is every element of A also in B?

$A$ is a subset of $B$ (written $A \subseteq B$) if every element of $A$ is also an element of $B$. Drag each token into $B$ below — a genuine element of $A$ will settle into place; anything that doesn't belong will bounce back out.

1.4.9 Proper Subsets — $\subset$

Contained, but not equal

$A$ is a proper subset of $B$ ($A \subset B$) when $A \subseteq B$ and $A \ne B$ — B must have at least one extra element A doesn't have. Using the checker above: since $A=\{10,20,30\}$ is missing 40 from $B$, $A \subset B$ as well as $A \subseteq B$. But if $A$ and $B$ were exactly equal, $A \subseteq B$ would still be true, while $A \subset B$ would not.

1.4.10 Disjoint vs. Overlapping Sets

Do they share anything?

Two sets are disjoint if $A \cap B = \varnothing$ — no shared elements at all. If they share at least one element, they're overlapping.

1.4.11 Power Set Explorer

All subsets of A, at once

The power set $P(A)$ is the set of all subsets of $A$ — including $\varnothing$ and $A$ itself. If $n(A) = m$, then $n[P(A)] = 2^m$, and the number of proper subsets is $2^m - 1$. Toggle elements on or off to assemble a candidate subset, then watch it fly into $P(A)$.

A = {}
n(A) = 2, so n[P(A)] = 2² = 4
