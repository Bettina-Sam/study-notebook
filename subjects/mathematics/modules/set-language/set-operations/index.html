1.5 Set Operations

Five ways to
combine two sets

Union, intersection, difference, symmetric difference and complement — five operations, and one diagram (the Venn diagram) that makes every one of them obvious at a glance.

01. The Five Operations

Notation you'll use constantly

A′Complement — everything in the universal set $U$ that is not in $A$. $A' = \{x : x \in U, x \notin A\}$.
∪Union — everything in $A$ or $B$ or both. $A \cup B = \{x : x \in A \text{ or } x \in B\}$.
∩Intersection — everything common to both $A$ and $B$. $A \cap B = \{x : x \in A \text{ and } x \in B\}$.
−Difference — elements in $A$ but not $B$ (or vice versa). $A - B = \{x : x \in A, x \notin B\}$.
ΔSymmetric Difference — everything in exactly one of the two sets. $A \Delta B = (A-B) \cup (B-A)$.

Worked Example

Example 1.14 (textbook)
If $A = \{-3,-2,1,4\}$ and $B = \{0,1,2,4\}$, find (i) $A - B$ (ii) $B - A$.
1
$A - B$: keep elements of A that are NOT in B.
A − B = {−3, −2}
2
$B - A$: keep elements of B that are NOT in A.
B − A = {0, 2}

Exercise 1.3 · Q5(iii)
Find the symmetric difference between $X = \{5, 6, 7\}$ and $Y = \{5, 7, 9, 10\}$.
$X \Delta Y = (X-Y) \cup (Y-X)$ — everything in exactly one of the two sets.
Answer: $X - Y = \{6\}$, $Y - X = \{9, 10\}$, so $X \Delta Y = \{6, 9, 10\}$
