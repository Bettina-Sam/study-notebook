Hook

Four sides can behave in very different ways

A quadrilateral is any four-sided polygon. The textbook builds a family: trapezium → parallelogram → rectangle/rhombus → square, with each extra condition creating stronger properties.

Key idea: every square is a rhombus and rectangle; every rhombus/rectangle is a parallelogram; every parallelogram is a trapezium under the textbook’s “at least one pair parallel” viewpoint.

Same base, same parallels → same height

MOVE THE TOP VERTEX — AREA STAYS THE SAME
Triangle area = 1/2 bh

Sliding the triangle’s top vertex along a line parallel to its base keeps the perpendicular height fixed, so its area does not change.

Quick Check

Why does a rhombus diagonal create right triangles?

Because the diagonals of a rhombus are perpendicular bisectors. This turns diagonal-length questions into Pythagoras problems — exactly what Exercise 4.2 uses.
