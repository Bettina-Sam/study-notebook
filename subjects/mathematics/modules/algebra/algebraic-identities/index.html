An identity is true for every value of the letters. Instead of memorising them, watch why they're true — as the area of a square or rectangle.

Identity
$(a+b)^2 = a^2 + 2ab + b^2$

Worked Example

Example
Expand $(2x + 3)^2$ using the identity.
Concept used: $(a+b)^2 = a^2 + 2ab + b^2$, with $a = 2x$ and $b = 3$.
1
Match to the identity: $a = 2x$, $b = 3$.
2
Write $a^2 + 2ab + b^2$.
$(2x)^2 + 2(2x)(3) + (3)^2$
3
Simplify each piece.
$4x^2 + 12x + 9$
4
Final answer
$(2x+3)^2 = 4x^2 + 12x + 9$

Try Yourself

Exercise
Expand $(x - 4)^2$ using the identity for $(a-b)^2$.
This matches $(a-b)^2 = a^2 - 2ab + b^2$ with $a = x$, $b = 4$.
$2ab$ here is $2 \times x \times 4 = 8x$.
Switch the tab above to (a−b)² and set a = 5, b = 4 to see the same pattern with numbers.
1
$x^2 - 2(x)(4) + 4^2$
2
$x^2 - 8x + 16$
Answer: $(x-4)^2 = x^2 - 8x + 16$
