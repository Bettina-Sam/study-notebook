You already know 2 + 3 = 5. Algebra asks: what if the number isn't fixed yet? A variable is just a placeholder for a number we haven't chosen — or one that keeps changing.

01. Variables

Watch a value change

A variable (usually a letter like $x$, $y$ or $a$) represents a number that can change. A constant is a fixed number that never changes, like 3 or −7. Combine them with $+, -, \times, \div$ and you get an algebraic expression.

Key idea

The expression is a rule, not a number

$x + 3$ isn't one number — it's a rule: "take whatever $x$ is, and add 3". Every time $x$ changes, the rule gives a new answer. That's the whole idea of algebra.

Why study polynomials?

The chapter begins by connecting familiar arithmetic with algebra. A number such as 5418 can be written as 5×10³ + 4×10² + 1×10 + 8. Replacing the base 10 by a variable gives the polynomial form 5x³ + 4x² + x + 8. This representation helps reveal number patterns, divisibility ideas, graphs and models used in science, engineering, economics and other fields.

Variable

A symbol such as x, y, z that can take different numerical values.

Constant

A fixed real number, such as 1, 5, −32, 7/3 or 8.432.

Algebraic expression

A combination of constants and variables using the four fundamental arithmetic operations.

Coefficient

The numerical factor multiplying the variable part of a term. In x²+5x−24, the coefficients of x² and x are 1 and 5; the constant is −24.
