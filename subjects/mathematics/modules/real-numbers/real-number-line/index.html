2.4 Real Numbers

Rational + Irrational = Real

The real numbers consist of all the rational numbers and all the irrational numbers. Any real number can be determined by a (possibly infinite) decimal representation.

2.4.1 The Real Number Line — Successive Magnification

Zoom in, one decimal place at a time

To place a decimal like $4.863$ precisely, don't try to eyeball the whole gap between $4$ and $5$ at once. Zoom in step by step: first find which tenth it's in, then which hundredth inside that tenth, then which thousandth inside that hundredth.

Example 2.15 (textbook)
Represent $3.\overline{45}$ on the number line, correct to 4 decimal places.
$3.\overline{45} = 3.454545\ldots \approx 3.4545$ (rounded to 4 places). Same successive-magnification method: 3 → 4 → 3.4 → 3.5 → 3.45 → 3.46 → 3.454 → 3.455 → 3.4545.
