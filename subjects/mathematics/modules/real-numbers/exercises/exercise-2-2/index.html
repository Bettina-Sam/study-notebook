Q1Express the following rational numbers as decimals and state the kind of decimal expansion.
(i) $\dfrac27$   (ii) $-5\dfrac{3}{11}=\dfrac{-58}{11}$   (iii) $\dfrac{22}{3}$   (iv) $\dfrac{327}{200}$

After watching the trace, classify this one:

(i) $\frac27=0.\overline{285714}$ — non-terminating recurring
(ii) $\frac{-58}{11}=-5.\overline{27}$ — non-terminating recurring
(iii) $\frac{22}{3}=7.\overline3$ — non-terminating recurring
(iv) $\frac{327}{200}=1.635$ — terminating (since $200=2^3\times5^2$)

Q3Express $\dfrac{1}{33}$ in recurring decimal form by using the recurring decimal expansion of $\dfrac{1}{11}$. Hence write $\dfrac{71}{33}$ in recurring decimal form.
$\frac{1}{11}=0.\overline{09}$, so $\frac{1}{33}=\frac13\times\frac{1}{11}=\frac13\times0.0909\ldots=0.\overline{03}$. Then $\frac{71}{33}=2+\frac{5}{33}=2+5\times\frac{1}{33}$.
$\frac{1}{33}=0.\overline{03}$, so $\frac{71}{33}=2+5(0.\overline{03})=2+0.\overline{15}=2.\overline{15}$

Q5Without actual division, find which of the following have a terminating decimal expansion.
(i) $\dfrac{7}{128}$   (ii) $\dfrac{21}{15}$   (iii) $\dfrac{49}{35}$   (iv) $\dfrac{219}{2200}$

Reduce to lowest terms first, then check whether the denominator's only prime factors are 2 and/or 5.

(i) $\frac{7}{128}$
(ii) $\frac{21}{15}$
(iii) $\frac{49}{35}$
(iv) $\frac{219}{2200}$
(i) $128=2^7$ → terminating.
(ii) $\frac{21}{15}=\frac{7}{5}$, $5=5^1$ → terminating.
(iii) $\frac{49}{35}=\frac{7}{5}$, $5=5^1$ → terminating.
(iv) $219$ and $2200$ share no common factor; $2200=2^3\times5^2\times11$ has a factor of 11 → non-terminating recurring.
