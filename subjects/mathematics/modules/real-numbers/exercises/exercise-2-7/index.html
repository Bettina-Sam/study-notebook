Q4If $x=\sqrt5+2$, find $x^2+\dfrac{1}{x^2}$.
First rationalise $\dfrac1x$, then compute $x+\dfrac1x$ — squaring that is faster than computing $x^2$ and $\dfrac{1}{x^2}$ separately.
$\dfrac1x=\dfrac{1}{\sqrt5+2}=\sqrt5-2$ (since $(\sqrt5+2)(\sqrt5-2)=1$). So $x+\dfrac1x=2\sqrt5$.
$x^2+\dfrac{1}{x^2}=\left(x+\dfrac1x\right)^2-2=(2\sqrt5)^2-2=20-2=18$.

Q5Given $\sqrt2=1.414$, find the value of $\dfrac{8-5\sqrt2}{3-2\sqrt2}$ (to 3 decimal places).
Rationalise by multiplying by the conjugate $3+2\sqrt2$ first — the denominator becomes a whole number.
Multiply by $\dfrac{3+2\sqrt2}{3+2\sqrt2}$: denominator $=9-8=1$. Numerator $=(8-5\sqrt2)(3+2\sqrt2)=24+16\sqrt2-15\sqrt2-20=4+\sqrt2$.
So the value is $4+\sqrt2=4+1.414=5.414$.
